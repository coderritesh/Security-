# 🛡️ SOC Analyst Journey

A practical, hands-on learning journey focused on Security Operations,
Blue Team operations, networking, Linux, SIEM, IDS/IPS, EDR and incident investigation.

## 🎯 Objective

Build practical SOC Analyst skills through:

- Security monitoring
- Log analysis
- Network security
- Linux
- Windows security
- IDS/IPS
- SIEM
- Threat intelligence
- EDR
- Incident investigation

## 🧪 Learning Method

Each topic follows:

Theory
↓
Practical Lab
↓
Evidence
↓
Investigation
↓
Documentation
↓
Interview Preparation
