# Day 01 — SOC Fundamentals

## 🎯 Objective

Understand the fundamentals of Security Operations Center (SOC)
operations and the role of a SOC Analyst.

## 📚 Topics Covered

- What is SOC?
- What does a SOC Analyst do?
- Security Events
- Security Alerts
- Security Incidents
- Event vs Alert vs Incident
- Security Logs
- Basic SOC Investigation

## 🛠️ Tools Used

- Windows Event Viewer
- Windows Security Logs

## 🧪 Practical Lab

A controlled Windows authentication investigation will be performed.

The lab will include:

1. Windows Event Viewer
2. Windows Security Logs
3. Failed Login — Event ID 4625
4. Successful Login — Event ID 4624
5. Authentication timeline

## 🔎 Investigation Method

During the investigation we will ask:

- WHO?
- WHEN?
- WHAT?
- WHERE FROM?
- WHAT NEXT?

## 📊 Important Event IDs

| Event ID | Description |
|---|---|
| 4624 | Successful Logon |
| 4625 | Failed Logon |
| 4672 | Special Privileges Assigned |
