
# Windows Authentication Investigation

## 1. Investigation Objective

The objective of this investigation was to analyze Windows authentication events generated during a controlled login test.

The purpose was to understand how Windows records failed and successful login attempts and how a SOC Analyst can investigate these events.

---

## 2. Investigation Environment

| Item | Details |
|------|---------|
| Operating System | Windows |
| Tool | Windows Event Viewer |
| Log Source | Windows Security Log |
| Test Type | Controlled Authentication Test |

---

## 3. Test Performed

A controlled authentication test was performed.

### Test Procedure

1. Opened Windows Event Viewer.
2. Navigated to:

```text
Windows Logs
→ Security

Event ID: 4625
Meaning: An account failed to log on

Event ID: 4624
Meaning: An account was successfully logged on

Incorrect Password
        ↓
4625 — Failed Logon
        ↓
Correct Password
        ↓
4624 — Successful Logon

4625 → 4624



Investigation Analysis

The observed pattern was:

4625 → 4624

This means a failed login was followed by a successful login.

In this controlled lab, the failed login was intentionally generated by entering the wrong password, followed by the correct password.

Therefore, this activity does not prove a brute-force attack.

A SOC Analyst should investigate additional context before classifying the activity as suspicious.

The basic investigation methodology used in this practical is:
