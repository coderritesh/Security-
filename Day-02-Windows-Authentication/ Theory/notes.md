# Day 2 — Windows Authentication & Event Logs

## 1. Windows Event Viewer

Windows Event Viewer is a built-in Windows tool used to view and investigate events generated by the operating system, applications, and security components.

It is useful for a SOC Analyst because Windows records authentication, system, application, and security-related activities as events.

### How to Open Event Viewer

```text
Win + R
→ eventvwr
→ Enter


Event Viewer
│
├── Windows Logs
│   ├── Application
│   ├── Security
│   ├── System
│   ├── Setup
│   └── Forwarded Events
│
└── Applications and Services Logs

Important Logs for SOC Investigation

Application

Records events generated by applications and software.

Security

Records security-related activities such as successful logons, failed logons, account management, and other security events.
This is one of the most important logs for authentication investigation.

System

Records events related to Windows services, drivers, hardware, and system components.

Setup

Contains events related to Windows installation and configuration.

Forwarded Events

Contains events collected from other computers when Windows Event Forwarding is configured.
Security Log Location

Windows event log files are stored at:

C:\Windows\System32\winevt\Logs\

Examples:

Security.evtx
System.evtx
Application.evtx
SOC Perspective

A SOC Analyst can use Event Viewer to investigate questions such as:

Who performed the activity?
When did it happen?
What happened?
Where did it originate?
How did the authentication occur?
What happened afterward?

The Security log is especially important when investigating Windows authentication events such as:

4624 → Successful Logon
4625 → Failed Logon
